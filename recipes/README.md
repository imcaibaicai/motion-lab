## 写手册的硬要求

1. **六件套齐全**：契约、禁用、门槛、失败模式、决策树、留白。
2. **门槛必须是数字**，不是形容词。
3. **失败模式表要持续长**：每踩一个新坑立刻加一行，这是省下未来所有试错的地方。
4. **明确写出"真正的旋钮只有 N 个"**：告诉 Agent 自由度在哪，别处不要乱动。
5. **独立撰写**：只借鉴思路，不复制第三方文本。来源写进末尾 `Source` 节。
